# Открытка на день рождения 🎉

Статичная поздравительная открытка по ссылке: получатель открывает подарок, видит заставку
с фейерверком, а дальше листает слайды — сама открытка, письмо с пожеланиями у торта,
фотографии (если добавлены) и финал.

Ни сервера, ни базы данных: всё содержимое открытки закодировано в хэше ссылки
(`index.html#<base64url>`). Хэш не уходит на сервер, поэтому открытка нигде не хранится
и не индексируется.

## Экраны

1. **Подарок** — 3D-коробка на CSS-трансформациях: шесть граней, объёмная крышка с лентой
   крест-накрест и бант, стоящий сверху. Коробка сама покачивается, на десктопе поворачивается
   за курсором, а при открытии крышка взлетает и улетает. Имя получателя под ней. Первый тап заодно снимает браузерный
   запрет на автозвук, поэтому музыка стартует именно здесь, и сразу ведёт на слайды.
2. **Слайды** — точки сверху, стрелки, свайп и стрелки клавиатуры:
   * **открытка** — имя, дата, подпись отправителя, кнопка «Открыть подарок»;
   * **пожелания** — 3D-торт с именем получателя на боку: его можно крутить мышью или пальцем,
     сам по себе он медленно вращается. Дальше заголовок печатается по буквам, а пожелания
     выходят нумерованным списком по одному; клик в любом месте показывает всё сразу;
   * **фото** — появляется, только если фотографии заданы;
   * **финал** — трое персонажей из 3D-модели пританцовывают (подпрыгивают с наклоном
     и приседают на приземлении, каждый со сдвигом по фазе, поэтому получается волна),
     и кнопка «Посмотреть заново» возвращает к подарку.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Открытка целиком |
| `create.html` | Конструктор: форма → готовая ссылка |
| `assets/js/shared.js` | Данные по умолчанию, темы, кодирование ссылки, разбор ссылок на музыку |
| `assets/js/card.js` | Логика открытки: экраны, слайды, конфетти, фейерверк, письмо |
| `assets/js/create.js` | Логика конструктора |
| `assets/css/style.css` | Все стили и объявления шрифтов |
| `assets/fonts/*.woff2` | Neucha, Balsamiq Sans и Nunito, кириллица и латиница |
| `assets/img/crew-*.webp` | Персонажи, отрисованные из 3D-модели |
| `tort.png` | Присланный рендер торта (в вёрстке не используется) |
| `tools/build-single.py` | Сборка всего в один файл (картинки инлайнит в data:URI) |

## Как сделать свою

1. Открыть `create.html`.
2. Заполнить: кому, от кого, дата, письмо, пожелания (по одному в строке), фото, музыка, тема.
3. «Создать ссылку» → скопировать или сразу отправить в WhatsApp.

Торт собран из тридцати панелей в цилиндр: кремовая крышка, потёки глазури, свеча-цилиндр
с живым огоньком и имя, выведенное «кремом» по окружности. Крутится перетаскиванием, между
касаниями крутится сам. Присланный рендер `tort.png` остался в репозитории как исходник,
но в вёрстке больше не используется.

Человечки на фоне — четыре отдельные SVG-фигуры (с тортом, с шариком, с табличкой и с конфетти),
разложенные по краям экрана; на узких экранах часть из них скрывается, чтобы не лезть в текст.

На финальном слайде стоят те же персонажи, но уже из 3D-модели `Meshy_AI_Birthday_Doodle_Celeb_*.glb`.
Сама модель весит 52 МБ и в страницу не помещается, поэтому она отрисована оффлайн через three.js
в headless-браузере, разрезана по связным областям на отдельные фигуры и сохранена в `assets/img/crew-*.webp`
(по 20–25 КБ). Скрипт разбора лежит в истории коммитов, модель в репозитории — исходник.

Коробка собрана из `div`-граней в общей сцене с `perspective`. Все размеры заданы в `em`,
а масштаб под экран задаёт `font-size` сцены — так одна модель тянется от телефона до десктопа.

Пасхалка: тап или клик по пустому месту рассыпает из точки нажатия фонтан из мандаринов,
денег и тортиков. На кнопках и ссылках не срабатывает и отключается при `prefers-reduced-motion`.

Чтобы отредактировать уже созданную открытку, откройте `create.html#<тот же хэш>` —
форма подставит все значения обратно.

## Фотографии

* **Ссылки** (по одной в строке) — предпочтительный вариант: ссылка остаётся короткой.
* **Файлы с устройства** — сжимаются до 900 px / JPEG q0.72 и вшиваются в ссылку. Удобно для
  1–3 фото; дальше ссылка становится очень длинной, и часть мессенджеров может её обрезать.

## Музыка

Поддерживаются YouTube (`youtube.com/watch?v=…`, `youtu.be/…`, параметр `&t=`),
Spotify (трек, альбом, плейлист — показывается родной мини-плеер) и прямые ссылки на
`.mp3 / .ogg / .wav / .m4a`. Кнопка ♪ в правом нижнем углу включает и выключает звук.

## Один файл

```bash
python3 tools/build-single.py
```

Собирает обе страницы в самодостаточные файлы:

* `dist/card.html` — открывается с диска, кладётся на любой хостинг, отправляется вложением;
* `dist/artifact.html` — то же без обёртки `doctype/html/body`.

Внутри одного файла роутинг по хэшу: `#make` — конструктор, любой другой хэш — открытка.

## Локальный запуск

```bash
python3 -m http.server 8000
# затем http://localhost:8000/
```

## Публикация

Репозиторий разворачивается как есть на GitHub Pages (Settings → Pages → Deploy from a branch),
Netlify, Vercel или любом статическом хостинге — сборка не нужна.

## Шрифты

Neucha для имени и подписей, Balsamiq Sans для заголовков, Nunito для текста — набор под
рисованных человечков. Файлы лежат в `assets/fonts` и подключаются через `@font-face`
с `unicode-range`, поэтому браузер тянет только нужный поднабор, а открытка не зависит
от Google Fonts и открывается без сети. В однофайловой сборке шрифты вшиты в data:URI.

## Доступность и мелочи

* Подарок открывается кликом, Enter и пробелом; у всех кнопок видимый фокус.
* Слайды листаются точками, стрелками, клавишами ← → и свайпом; на узком экране стрелки
  уезжают вниз, чтобы не лежать поверх текста.
* При `prefers-reduced-motion` конфетти, фейерверк, фонтан по тапу и печать текста
  отключаются — письмо показывается сразу целиком.
* Мобильная вёрстка учитывает вырезы экрана (`env(safe-area-inset-*)`), точки-переключатели
  имеют увеличенную область нажатия, для низких экранов в альбомной ориентации свои отступы.
* Темы: праздник, лимон, мята, небо, карамель — все светлые.
